How PDFBuddy works

Choose a tool, select files, set any options, and download the result. This independent project focuses on everyday PDF tasks. Compression, Word conversion, PDF-to-image export, and password protection are planned but not yet available.

1. Choose a tool

Pick Merge, Split, Rotate, Reorder, Delete pages, or JPG to PDF.

2. Add your files

Select files from your device. Supported tools run in your browser.

3. Download

Open the downloaded PDF and check the result.
